# Sistema de Gestión de Biblioteca

## Tecnologías
- Java 21
- springboot
- spring security
- css
- html 
- MySQL 8
- mongodb (opcional)

## Funcionalidades
- Inicio de sesión
- creacion de cuentas para usuarios nuevos 
- Gestión de usuarios
- calculo de imc
- posibilidad de apartar citas
- visualizar tus citas
- agendar citas con IA ( el crud completo )
- modelo predictivo con weka - arbol de decision
- modulo interactuvo de alimentos ingeridos y calculo de valores nutricionales }
- consulta de historial clinico
- recomendaciones medicas guardadas en mysql
- conexion con mysql y mongodb 

## Instalación
1. Clonar el repositorio
2. Crear la base de datos con el script `base de datos PA.sql`
3. Configurar credenciales en `en application.properties`
4. Ejecutar el proyecto
